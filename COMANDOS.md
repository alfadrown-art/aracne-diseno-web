# Chuleta de comandos — Agente Diseño Web Aracne

Escribe el comando al inicio del mensaje para activar la skill.

---

## Diseño e interfaz

| Comando | Para qué sirve |
|---------|----------------|
| `/frontend-design` | Sistema visual completo: colores, tipografía, espaciado, layout general |
| `/ui-ux-designer` | Estructura de navegación, flujos de usuario, wireframes |
| `/shadcn` | Instalar y componer componentes shadcn/ui |
| `/tailwind-design-system` | Configurar design tokens y tema en `tailwind.config.ts` |
| `/web-design-guidelines` | Principios de diseño aplicados al proyecto |

---

## Desarrollo

| Comando | Para qué sirve |
|---------|----------------|
| `/react-ui-patterns` | Patrones de componentes React reutilizables |
| `/nextjs-best-practices` | Convenciones y optimizaciones Next.js |
| `/nextjs-app-router-patterns` | Routing, layouts, loading states, error boundaries |
| `/react-nextjs-development` | Desarrollo full-stack React + Next.js |

---

## Páginas y conversión

| Comando | Para qué sirve |
|---------|----------------|
| `/landing-page-generator` | Generar estructura y secciones de una landing page |
| `/page-cro` | Optimizar una página para conversión (CTAs, flujo, fricción) |

---

## Copy y SEO

| Comando | Para qué sirve |
|---------|----------------|
| `/aracne-copywriter` | Textos de la web que no suenen a IA |
| `/aracne-seo` | Auditoría SEO de la web antes de entregar |
| `/seo-meta-optimizer` | Titles, metas y H1 de cada página |

## Frases de ejemplo para empezar

```
/frontend-design Necesito el sistema visual para una web de consultoría logística.
Color corporativo: azul marino. Tono: profesional pero cercano.

/landing-page-generator Landing page para un servicio de automatización de facturas.
Audiencia: directores financieros de pymes.

/shadcn Quiero un hero con imagen a la derecha, headline, subtítulo y dos botones CTA.

/aracne-copywriter Escribe el hero y la sección de beneficios para una web de asesoría RRHH.

/aracne-seo Audita esta web antes de entregar: [URL del cliente]

/ui-ux-designer Diseña el flujo de navegación para una web corporativa con 5 páginas.
```

---

## Flujo habitual de un proyecto nuevo

```
1. /ui-ux-designer      → estructura y flujos
2. /frontend-design     → sistema visual
3. /aracne-copywriter   → textos de cada sección
4. /shadcn              → componentes y maquetación
5. /page-cro            → revisar conversión
6. /aracne-seo          → auditoría final
```
