# Proyectos de diseño web — Aracne

Cada cliente tiene su propia carpeta con tres archivos estándar:

| Archivo | Contenido |
|---------|-----------|
| `brief.md` | Briefing inicial: objetivo, audiencia, páginas, referencias, deadline |
| `diseno.md` | Sistema visual: colores, tipografía, componentes, decisiones de diseño |
| `entrega.md` | URLs de producción, accesos, instrucciones de edición para el cliente |

## Cómo crear un nuevo proyecto

```bash
mkdir proyectos/nombre-cliente
touch proyectos/nombre-cliente/brief.md
touch proyectos/nombre-cliente/diseno.md
touch proyectos/nombre-cliente/entrega.md
```

O pídele a Claude que lo cree con el briefing del cliente.
